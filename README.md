# CREST — Conversion and Rewriting Engine for Scheme Transformations

Experimental ChezScheme bindings for MLIR, enabling pattern development in Scheme.

**⚠️ Status: Initial Development**

This repository is under active development. Documentation and code coming soon.

## What is CREST?

CREST provides ChezScheme FFI bindings to the MLIR C API, allowing developers to write MLIR conversion patterns and rewrite patterns in Scheme rather than C++.
